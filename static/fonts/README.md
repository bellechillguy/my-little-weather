# Creampuff

Creampuff by Nick Curtis, copyright (c) 1999 Nick Curtis.

Source: https://fontsme.com/creampuff.font
Original download: https://files.fontsme.com/c/231/2231/file/creampuff.regular.ttf

The source lists this font as free for personal use. This copy is included for this personal coursework project. Confirm licensing with the author before commercial redistribution.

The original is preserved as `creampuff.ttf`. The browser font `creampuff.woff` was rebuilt using FontTools FontBuilder from the original glyph outlines, Unicode mapping, and advance widths. The old font contains malformed tables rejected by this browser. Outline shapes, author credit, and embedding permissions are preserved; legacy hinting and kerning tables are omitted.

Montserrat is loaded separately through Google Fonts.
